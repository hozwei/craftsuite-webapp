# Security

Please report security problems privately through GitHub's private vulnerability reporting: on
this repository, *Security* → *Report a vulnerability*
([direct link](https://github.com/hozwei/craftsuite-webapp/security/advisories/new)). Do not open a
public issue for them.

Problems in the Craft apps themselves belong to their projects at
[github.com/storytold](https://github.com/storytold); problems in the translator or the Nextcloud
app to [nextcloud-craftsuite-layer](https://github.com/hozwei/nextcloud-craftsuite-layer).

The security model of this setup is described in
[docs/how-it-works.md](docs/how-it-works.md#security-model).
